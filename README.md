# Business Performance & Sales Intelligence Platform

Beginner-friendly end-to-end Data Analyst portfolio project using Excel, Power Query, SQL, Power BI, DAX and Python.

**Synthetic portfolio data — no real customer data.**

## Final scale
- 2,000 customers
- 300 products
- 18 stores
- 17,020 raw order rows
- 17,000 cleaned order rows
- 3 full years: 2023–2025

## Why this scale?
The dataset is large enough for realistic SQL, Excel and Power BI analysis but small enough for a beginner to inspect, clean and explain confidently.

## Workflow
Raw → Data Quality → Power Query → Excel → SQL → Star Schema → DAX → Power BI → Insights

## Important data convention
`discount_pct` is stored as percentage points. Example: `7.87` means **7.87%**.

## Portfolio components
- Intentional data-quality issues and cleaning rules
- Power Query ETL scripts
- Excel analysis workbook
- 36 SQL queries
- Star-schema DDL
- DAX KPI library
- 4-page Power BI blueprint
- Evidence-based insights
- Interview defense guide

**Synthetic portfolio simulation only.**
