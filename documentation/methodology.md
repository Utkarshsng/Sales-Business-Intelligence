# Methodology

1. Generate synthetic master data for customers, products and stores.
2. Generate four years of transactional orders with correlated customer, product,
   store, pricing, discount and return behavior.
3. Preserve a clean reference dataset for validation.
4. Create a raw analytical dataset containing controlled data-quality issues.
5. Profile the raw data.
6. Clean and validate using Power Query/Excel and SQL.
7. Load validated tables into a relational database.
8. Build analytical SQL queries.
9. Create a star-schema model in Power BI.
10. Build reusable DAX measures.
11. Create four management-oriented Power BI pages.
12. Interpret results and write evidence-based recommendations.

Important: final business insights must be calculated from the cleaned dataset rather
than pre-written into the project narrative.
